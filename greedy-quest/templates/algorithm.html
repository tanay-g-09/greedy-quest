How Greedy Best-First Search works

GBFS is a search strategy that always expands whichever node in the open list appears closest to the goal right now — nothing more.

f(n) = h(n)

On this grid, h(n) is Manhattan distance:

h(n) = |x − goal_x| + |y − goal_y|

The open list is a priority queue ordered strictly by h(n). That's the entire algorithm: pop the smallest-h node, check if it's the goal, otherwise push its unvisited neighbors and repeat. It never looks at g(n), the cost already paid to get there — which is exactly what separates it from A*.

This is an educational comparison — Greedy Quest's actual solver is always GBFS.

Why GBFS isn't always optimal

Because GBFS ignores path cost, it can commit early to the direction that looks best and get stuck detouring around an obstacle, even when a slightly-less-tempting-looking route would have been shorter overall.
