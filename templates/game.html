How does Greedy Best-First Search work?

›

Greedy Best-First Search always expands whichever node in the open list currently looks closest to the goal — it orders that list purely by the heuristic estimate:

f(n) = h(n)

For this grid, the heuristic is Manhattan distance:

h(n) = |x − goal_x| + |y − goal_y|

Unlike A*, GBFS never adds in g(n), the cost already spent reaching a node. That makes it fast and goal-directed, but it can be lured into a detour by an obstacle sitting between it and the direction that looks most promising — see Challenge Level 3, "Greedy Trap".
